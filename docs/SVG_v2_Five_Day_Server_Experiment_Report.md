# SVG-v2 五天精简方案：服务器实验报告

日期：2026-08-01

## 1. 结论

本轮完成了 SVG-v2 的两折开发筛选、组合筛选、候选冻结、ADHD/WMRC 三折三 seed 确认性 OOF，以及 F0 短期分支融合验收。

最终结论：**不将 SVG-v2 候选升级为默认架构，继续保留 `signed_gin_multibranch_late_fusion` 作为默认 SVG 架构。**

原因：开发筛选冻结的 `G2` 在完整 OOF 中未稳定复现增益；以 outer-fold AUC 的算术平均作为主指标时，ADHD 和 WMRC 的三 seed 平均 AUC、Site-AUC 均未超过当前默认架构。F0 在 ADHD 的 mean-fold AUC 较高，但主要继承短期分支的性能，跨站点指标和 WMRC 结果不足以通过跨数据集验收。

## 2. 实验协议

- 数据集：ADHD（938 样本）与 WMRC（546 样本）。
- 开发阶段：只读取 fold 0、1 的 inner-validation；候选冻结前不生成 outer-test 结果。
- 确认阶段：冻结候选后运行 3 folds × seeds 42、43、44 的严格 OOF。
- F0：每个 outer fold 只用该折 inner-validation 拟合校准器、非负融合权重和阈值，再冻结应用于 outer-test。
- Selector、数据划分和现有硬图协议均保持冻结。
- 两台 RTX 5090 分别承担 ADHD 和 WMRC，未改变统计协议。
- 分类性能主指标：每个 seed 先对三个 outer fold 的 AUROC 作算术平均，再汇总三个 seed 的均值和标准差。Pooled OOF AUROC 仅作为辅助诊断，不用于候选晋升。

## 6. F0 短期分支融合

F0 使用 validation-fitted、非负 L1 收缩融合；每个 outer fold 的拟合样本与评估样本完全分离。

| WMRC | Mean-fold Site-AUC | 0.515672 | 0.579615 | 0.542583 | 0.545957 ± 0.026213 |
| WMRC | BA | 0.513768 | 0.546906 | 0.525121 | 0.528598 ± 0.013750 |
| WMRC | Accuracy | 0.516484 | 0.571429 | 0.514652 | 0.534188 ± 0.026344 |

作为参照，冻结短期分支单独 OOF 为：

- ADHD：mean-fold AUC 0.658318 ± 0.022524，mean-fold Site-AUC 0.452650 ± 0.009301，OOF总体BA 0.583811，OOF总体Accuracy 0.608742。
- WMRC：mean-fold AUC 0.472725 ± 0.045731，mean-fold Site-AUC 0.477683 ± 0.043727，OOF总体BA 0.506699，OOF总体Accuracy 0.468864。

解释：

- ADHD F0 的 mean-fold AUC 仅比短期分支提高约 0.0012，未达到 0.005 门槛；mean-fold Site-AUC 提高约 0.0061，也未达到 0.01 门槛。
- WMRC F0 虽优于较弱的短期分支，但 mean-fold AUC 0.546633 低于当前 SVG 基线 0.561294，与 G2 三 seed 均值 0.546358 基本相同。
- 因此 F0 不具备稳定、跨数据集的增益证据，不晋升为默认融合模型。

## 7. 最终决策

1. 默认 SVG 架构保持 `signed_gin_multibranch_late_fusion`。
2. G2（有符号谱演化方向辅助监督）保留为研究性候选，不作为正式默认架构。
3. `C3_G2` 组合淘汰。
4. F0 保留为无泄漏的融合实验入口，但不作为默认推理路径。
5. 本轮结果说明：两折验证增益不足以代表跨折、跨 seed 稳定增益，后续架构升级必须以完整 OOF 为最终依据。
