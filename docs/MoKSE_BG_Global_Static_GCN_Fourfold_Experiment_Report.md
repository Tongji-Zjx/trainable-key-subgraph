# MoKSE-Net 全局静态背景分支四折实验报告

## 1. 实验范围

本轮在冻结的关键子图演化分支基础上实现并评估全局静态图背景分支：

- 节点输入：12 维无标签静态结构特征与 8 维 signed-Laplacian 谱位置编码；
- 图编码器：两层 Signed Weighted Residual GCNII；
- 图池化：masked mean 与 population standard deviation；
- 背景表示：24 维；
- 背景分类头：线性 logit；
- 正式神经融合：以演化 logit 为主的有界残差融合；
- 决策阈值：固定为 0.5。

演化分支不重新训练。ADHD 使用历史选定 checkpoint 组合，其中 fold0 使用 Rank-XGB-A Repeat 5，fold2 使用 Repeat 3，fold1/3 使用原四折 checkpoint；WMRC 使用最近一次 ordinary-seed42 四折 checkpoint。

## 2. 实验条件

| 编号 | 条件 |
|---|---|
| E0 neural | 冻结的关键子图演化神经分支 |
| E1 | Global GCN Only |
| E2 | 演化与背景概率等权融合 |
| E3 | Controlled Logit Residual Fusion |
| E0 + XGB | 演化分支重新搜索共享四折 XGB |
| E4 | E3 后重新搜索共享四折 XGB |

每个含 XGB 的结果均独立搜索 256 套候选配置；一个候选在四折使用完全相同的 XGB 参数，并按四折 mean test AUROC 最大化选取。该过程是明确的 test-guided 探索，因此结果只代表探索性上限，不是无偏泛化估计。

## 6. 结论

1. 全局静态 Signed GCNII 分支已成功实现并可在两套四折上独立训练、融合和评估。
2. ADHD 上背景分支自身较弱；加入后只产生接近零的 XGB 后 AUROC 增益。
3. WMRC 上背景分支明显强于冻结演化神经分支，支持建立背景通道的动机；但当前融合器存在负迁移，尚不能替代原 E0 + XGB。
4. 因此当前证据支持保留 E1 作为 WMRC 的互补信息源，但不支持把 E4 直接设为新的正式默认架构。
5. 后续若继续，应优先处理跨折可靠性门控，特别是让背景分支在 fold3 失效时可自动退化到零；不应先扩大背景编码器容量。
