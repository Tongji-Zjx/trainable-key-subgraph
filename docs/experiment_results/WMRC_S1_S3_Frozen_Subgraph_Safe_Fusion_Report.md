# WMRC S1–S3 与冻结子图分支安全融合报告

## 1. 实验设置

- 数据集：WMRC。
- 划分：固定 20% test；其余 development 样本进行四次互斥 validation 轮换。
- 静态分支：已经完成训练的 S1、S2、S3 四轮模型。
- 子图分支：四轮冻结的 TGE 神经表示与既有 XGBoost 残差头，全程不更新。
- 融合：保持 logit 零点的尺度对齐与共享凸权重搜索。
- 权重网格：子图权重 `a ∈ {0, 0.05, ..., 1}`。
- 权重选择：只使用四个 development validation rotation；固定 test 不参与选择。
- 决策阈值：固定为 0.5。
- 本轮没有重新训练 selector、轨迹编码器、子图 XGB 或静态 GNN；“训练”仅指在 development validation 上拟合共享安全融合决策。

冻结子图 XGB 的 validation logit 由已保存的四个 booster 只读复放得到。复放产生的 test logit 与历史持久化预测逐样本完全一致，最大绝对差为 0。

> 既有 WMRC 子图 XGB 超参数历史上使用 test-guided 规则确定。因此本报告适合比较当前冻结系统中的增量融合效果，但不能被解释为一套从未接触 test 的全新无偏泛化估计。

## 6. 结论

1. S1–S3 与冻结子图分支的安全融合流程均已完成，但 development validation 均选择 `a=0`，没有形成真正的双分支混合。
2. 固定 test 上，三套最终输出均低于冻结子图分支；S3 是三者中损失最小者，但 mean AUROC 仍下降约 0.039683。
3. development validation 与固定 test 的分支优劣发生反转：静态分支在 development 明显更好，在 test 却更差。这是当前融合失败的核心证据，说明静态信号存在明显的轮换/测试分布不稳定性。
4. 因而本轮不能宣称静态背景分支提高了 WMRC 分类性能，也不应依据固定 test 反向调节融合权重。
5. 下一步若继续改进融合，应优先处理跨 rotation 的静态 logit 稳定性和门控可靠性；在此之前，不建议增加第二个 XGB 或扩大融合器容量。
