# ADHD S1–S3 与冻结子图分支安全融合报告

## 1. 实验设置

- 数据集：ADHD。
- 静态分支：已经完成训练的 S1、S2、S3 四轮模型。
- 子图分支：冻结的历史完整子图正式分支及其 XGBoost 残差头，不更新任何参数。
- 子图基线（四轮 test 均值）：Accuracy 0.630319，AUROC 0.619237。
- 融合形式：先在 development validation 上进行零点保持的 logit 尺度对齐，再搜索一个四轮共享的凸融合权重。
- 权重定义：`a` 为子图 logit 权重，最终 logit 为 `a × subgraph + (1-a) × scaled_static`。
- 权重网格：`a ∈ {0, 0.05, ..., 1}`。
- 安全门：仅使用四个 development validation rotation 检查平均 AUROC 增益、非下降轮数、最差轮下降和 Site-AUC 下降。
- 固定 test 不参与融合权重选择；分类阈值固定为 0.5。
- 四个 rotation 使用同一个固定 test cohort，因此主结果报告“四轮模型在固定 test 上的指标均值”，并另外给出四轮 logit ensemble。

冻结子图 XGB 的 validation logit 由既有 booster 只读复放产生；复放后的 test logit 与历史持久化预测逐样本完全一致，最大绝对误差为 0。

> 历史子图 XGB 超参数曾使用 test-guided 规则确定。因此，本报告适合评价“在既有冻结正式系统上加入静态分支”的增量效果，不能解释为一套从未接触 test 的全新无偏性能估计。

## 6. 结论

1. S1–S3 与冻结子图分支在 ADHD 上的安全融合训练（development 权重拟合）和固定 test 评估均已完成。
2. S1 和 S2 明确产生 test 负迁移，应排除；其中 S2 在 validation 上直接选择纯静态路径，显示 validation 与 test 的分支优劣不一致。
3. S3 是唯一可保留的候选：四轮平均 Test Accuracy 从 0.630319 提高到 0.640957，AUROC 从 0.619237 微升至 0.620621。
4. 但 S3 的 AUROC 增益很小、逐轮不稳定，并伴随 Site-AUC 下降。因此本轮不能宣称静态分支为 ADHD 带来了可靠正向增益，也不足以替换冻结子图正式分支。
5. 若继续研究，S3 应只作为候选融合分支；下一步应针对 validation–test 排序反转和跨轮可靠性设计门控，而不能利用固定 test 反向选择权重。
