# SV-HardSGW 神经谱演化分支：实现与配对 OOF 验证

## 1. 目的

在不改变硬关键子图、冻结 selector 和 Static-spectral 基线（S）的前提下，用学习型时序分支 E 替代人工 16 维 Variation 汇总，并检验：

1. E 是否为 S 带来可泛化的分类增益；
2. 增益是否真正依赖时间顺序，而不只是差分集合。

本实验不重新训练 selector，不重算硬图，不接触外折测试集阈值。

## 2. 实现

### 2.1 输入

每个有效窗口使用与旧 Variation 完全一致的 16 个 signed-Laplacian 谱分位数：

\[
q_m\in\mathbb{R}^{16}.
\]

相邻有效窗口形成 32 维有符号差分：

\[
d_m=[q_m-q_{m-1},\ |q_m-q_{m-1}|].
\]

程序逐样本检查：

\[
\operatorname{mean}_m |q_m-q_{m-1}|
=\text{旧 Variation}.
\]

无效窗口会切断序列；TCN 不跨缺失窗口传播。不同样本的转移长度保持可变，不截断。

### 2.2 神经演化分支

```text
32-D transition
  → Linear(32,32) + GELU + LayerNorm
  → 2-layer Masked Residual TCN
       kernel=3, dilation=(1,2), hidden=32
  → masked mean + std pooling
  → Linear(64,16) + GELU + LayerNorm
  → 16→16→2 dynamic head
```

最终分类采用静态锚定残差：

\[
z=z_S+\sigma(g)\,z_E.
\]

- S 为每折已有的 `static_spectral_only` 最佳 checkpoint，训练时完全冻结；
- E 和非负标量门控可训练；
- 动态输出层零初始化，因此训练开始时 \(z=z_S\) 精确成立；
- 主损失为融合输出的类别加权交叉熵；
- E 的辅助分类损失权重为 0.25；
- 模型仍由 inner-validation 选择 checkpoint 和分类阈值。

### 2.3 时间顺序对照

`SE_shuffled` 不重新训练模型，只在推理时以固定种子 2026 打乱每个连续有效片段内的转移顺序：

- 转移数量与数值集合不变；
- mask、样本、标签和 checkpoint 不变；
- 使用原 SE 在 inner-validation 冻结的同一阈值。

## 3. 验收

- 服务器新增测试：5 项全部通过；
- 六个外折均生成最佳 checkpoint、validation 结果、原序 test 结果和打乱 test 结果；
- WMRC：546 个样本各获得且仅获得一次 OOF 预测；
- ADHD：938 个样本各获得且仅获得一次 OOF 预测；

## 5. 诊断

- 最佳门控均值：WMRC 0.1170，ADHD 0.1332；E 确实参与了输出，但未覆盖 S。
- 最佳 epoch：WMRC 为 18、3、8；ADHD 为 25、12、7。
- 多个外折中，训练 AUROC 很快接近 1.0，而 validation/outer-test 没有同步改善，表明 E 容量主要被用于拟合折内特异波动。
- 打乱时间顺序后，平均概率变化并非零（WMRC 0.0239，ADHD 0.0944），说明 TCN 数值上对顺序敏感；但 OOF 排序能力没有稳定下降，所以这种顺序敏感性没有转化为可泛化判别信息。

## 6. 结论

本次预定义的神经动态分支未通过升级判据，应保留 S 为当前默认架构。

更具体地说：

1. 不能声称 E 提高分类性能：两个数据集的 `SE − S` 均为负，且置信区间跨 0；
2. 不能声称模型学到了可泛化的时间顺序判别结构：`SE − SE-shuffled` 在两个数据集上都接近 0；
3. 结果不否定“动态图演化可能有信息”，但否定了当前“小型差分 MLP + Residual TCN + mean/std”实现已经提取到稳定增量；
4. 不建议通过增加 TCN 宽度、层数或训练 seed 继续堆算力；现有主要问题是折内过拟合，而不是容量不足。

如继续研究神经动态分支，下一步应优先降低监督自由度，例如用自监督的相邻状态预测或排序预训练，再用很小的冻结表示分类头验证，而不是直接扩大端到端分类器。
