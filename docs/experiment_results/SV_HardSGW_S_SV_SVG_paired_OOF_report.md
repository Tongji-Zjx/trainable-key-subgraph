# SV-HardSGW：S / SV / SVG 配对 OOF 消融报告

## 1. 实验问题

比较三个严格嵌套的分类架构：

- **S**：Static-spectral only；
- **SV**：Static-spectral + Variation；
- **SVG**：Static-spectral + Variation + SignedGIN。

目标是分别判断：

1. Variation 在 Static-spectral 之上是否带来稳定增益；
2. SignedGIN 在 SV 之上是否带来稳定增益。

## 2. 实验控制

- 数据集：WMRC（546 个 OOF 样本）与 ADHD（938 个 OOF 样本）；
- 外折：复用两数据集已经冻结的 3-fold OOF；
- S、SV、SVG 在同一数据集内复用完全相同的：
  - outer fold；
  - fold-local selector；
  - 硬图缓存；
  - train-only scaler；
  - 训练 seed 42；
  - 训练预算和早停规则；
- checkpoint 仅由 inner-validation 的 composite AUC 选择；
- 分类阈值仅由各折 inner-validation 确定，然后冻结到 outer-test；
- test 未用于调参、选 checkpoint 或拟合阈值；
- AUC 差值使用 10,000 次分层 bootstrap 95% CI 与 10,000 次配对交换检验。

完整性检查通过：六份模型 OOF 汇总均满足“每个样本恰好预测一次”“预测与冻结外折一致”“未在 test 拟合阈值”。

## 4. 结论

1. **没有证据表明 Variation 能稳定提高 OOF AUC。**  
   SV − S 在两个数据集上的点估计均为负，且置信区间均跨越 0。

2. **没有证据表明 SignedGIN 能在 SV 上提供稳定的增量分类价值。**  
   SVG − SV 在两个数据集上的点估计均为正，但幅度仅为 +0.0073 和 +0.0146，置信区间均跨越 0，配对检验均不显著。

3. **也不能据此断言 SignedGIN 必然有害。**  
   WMRC 中 S 的 AUC 数值最高；ADHD 中 SVG 的 AUC 数值最高，但所有架构差异都处于当前不确定区间内。

4. **从分类性能与模型简约性出发，S 是当前最有证据支持的精简候选。**  
   它在 WMRC 上取得最高 AUC，在 ADHD 上与 SVG 的差距仅 0.0081，且没有额外 Variation 或 GIN 复杂度。

5. **若模型必须显式表达“演化”，可保留 SV 作为理论构造版本，但不能声称 Variation 已带来分类增益。**  
   当前结果不支持继续把 SignedGIN 作为分类性能所必需的默认分支。

## 5. 解释边界

- 本实验使用一个训练 seed；bootstrap 与置换检验刻画的是 OOF 样本不确定性，不包含优化 seed 不确定性。
- 三种架构的外折、数据产物和训练协议一致，但不同架构的随机初始化权重并非逐参数绑定。
- 因此可以得出“当前没有检测到增量收益”，不应扩大为“Variation 或 SignedGIN 在所有实现中都无效”。
