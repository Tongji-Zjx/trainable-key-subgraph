# SVG + 短期分支表示级 F2 实验报告

## 实验目的

将此前的低成本决策级 F2 提升为真正读取短期分支隐藏表示的残差模型，并检验其是否能稳定改善冻结 G2。

## 架构

- 锚点：冻结 G2-D16 二分类 logit；
- 残差信息：冻结作者短期分支的 `final_representation`；
- ADHD 短期表示：448 维；
- WMRC 短期表示：352 维；
- 残差头：`LayerNorm → Linear(D,64) → GELU → Dropout(0.2) → Linear(64,1)`；
- 最后一层权重和偏置初始化为 0；
- 全局门控初值为 0.01；
- 融合公式：`logit_F2 = logit_G2 + sigmoid(gate) × residual(ST_representation)`；
- 仅训练残差头和门控，G2与短期分支参数均冻结；
- 辅助目标：预测 `label − sigmoid(G2_logit)` 的概率残差；
- validation 负责 checkpoint 与阈值选择，outer-test 不参与训练或阈值拟合。

初始化时残差严格为0，因此模型输出与冻结G2完全相同。

## 与低成本决策级 F2 对比

| 数据集 | 决策级 F2 Mean-fold AUC | 表示级 F2 Mean-fold AUC | 表示级−决策级 |
|---|---:|---:|---:|
| ADHD | 0.673403 | 0.573535 | -0.099868 |
| WMRC | 0.571538 | 0.571538 | +0.000000 |

ADHD上的决策级F2直接使用已经具有较强排序能力的短期分支logit；表示级残差头没有从其高维隐藏表示中重新学出同等的可泛化排序。WMRC短期分支较弱，两种F2都收缩到G2附近。

## 结论

1. 表示级F2实现和三折实验流程均通过技术验收；
2. 它在ADHD只产生极小增益，在WMRC没有增益；
3. 它没有复现决策级F2在ADHD上的优势；
4. 当前结果不支持将表示级F2设为默认融合方式；
5. 默认仍应保留此前的决策级F2候选。

若继续改进表示级融合，关键不是增加残差头容量，而是让融合训练看到未被基础模型训练过的短期表示，例如严格的inner cross-fitted representation；该方案计算成本明显更高，应作为独立后续实验。
