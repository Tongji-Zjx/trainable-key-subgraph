# S3-XGB与冻结子图分支安全融合：ADHD/WMRC四轮评估报告

## 1. 实验目的与规则

本实验检验：在冻结S3 Signed GCNII和冻结子图正式分支的条件下，能否使用浅层XGBoost残差头改善S3的排序能力，并进一步改善双分支安全融合。

- S3神经网络、selector、子图轨迹分类器和子图XGB全部冻结。
- S3-XGB输入为S3的24维图表示与1维原始S3 logit，共25维。
- XGB以S3 logit作为`base_margin`，只学习残差。
- 每个候选的全部XGB参数、树轮数、残差系数、正类权重和XGB seed在四轮之间完全共享。
- ADHD和WMRC分别搜索一套数据集内共享配置。
- 每个数据集评估96个候选。
- 按四轮平均Test AUROC、平均Test ACC、最差轮Test AUROC依次选择XGB配置，属于明确的test-guided探索。
- 获胜XGB配置确定后，子图/S3-XGB融合权重仍只使用四个development validation rotation选择。
- 分类阈值固定为0.5。

融合公式为：

\[
\ell_{S3-XGB}=\ell_{S3}+\beta r_{XGB},
\]

\[
\ell_{final}=a\ell_{subgraph}+(1-a)r\ell_{S3-XGB},
\]

其中，\(\beta\)是四轮共享的XGB残差系数，\(a\)是validation选择的共享子图权重，\(r\)是由development validation估计的零点保持尺度系数。

> 由于XGB配置按test表现选择，本报告反映探索性上限，不是无偏泛化估计。它不能与完全不接触test的确认性结果作同等统计解释。

## 3. WMRC结果

### 3.1 选中配置

WMRC的最佳trial为0，即精确的“XGB残差关闭”对照：

\[
\beta=0.
\]

虽然booster被拟合，但其输出不参与S3最终logit。因此96个候选中，没有任何启用XGB残差的配置在最终四轮平均Test AUROC上超过原S3路径。

- 子图权重：\(a=0\)，即纯S3；

## 4. 综合结论

1. ADHD上，S3-XGB与子图安全融合形成小幅探索性增益：平均Test AUROC从0.619237提高到0.623540，ACC从0.630319提高到0.639628。
2. ADHD增益来自双分支排序互补，而非S3-XGB单分支变强；S3-XGB单分支AUROC反而从0.587186下降到0.582671。
3. WMRC上，最优候选自动退化为\(\beta=0\)，说明加入XGB没有改善S3，最终路径仍明显弱于冻结子图分支。
4. 因而S3-XGB不能作为跨数据集通用改进。它最多可作为ADHD上的探索性候选，不应替换当前正式子图架构。
5. WMRC的核心问题仍是validation与固定test之间的分支排序反转，尤其rotation 3异常；扩大树容量或继续test-guided搜索不是可靠解决方案。
